# 밸런스픽

8개의 밸런스 질문에 답하고 선택 성향을 확인하는 앱인토스 비게임형 미니앱 MVP입니다.

## 구현된 흐름

- 랜딩 화면 → 8문항 선택 → 참여 비율 → 성향 결과
- 네 가지 결과 유형: 번개형 직진러, 계획형 해결사, 공감형 평화주의자, 호기심형 탐험가
- 토스 딥링크와 네이티브 공유 시트를 이용한 결과 공유

## 시작하기

```bash
nvm use
npm install
npm run dev
```

Node.js 24 이상을 권장합니다.
